# CodeAlpha Stock Portfolio Tracker

## Description
A simple Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship.

## Features
- Uses a hardcoded stock price dictionary
- Accepts stock names and quantities from the user
- Calculates investment for each stock
- Calculates total investment
- Console-based program

## Technologies Used
- Python
- Dictionary
- Input and Output
- Arithmetic operations
- While loop
- If-else statements

## How to Run
1. Download or clone the repository.
2. Open the project in VS Code.
3. Run `stock_portfolio.py`.
4. Enter the stock name and quantity.
5. Enter `done` to finish.
